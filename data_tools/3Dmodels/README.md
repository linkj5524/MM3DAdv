# Blender 车辆3D模型标准化预处理操作规范
## 文档用途
本文件规定使用Blender对车辆三维模型进行预处理的完整流程，统一适配后端3D对抗伪装算法（LatentAdv物理场景模块）输入要求：
1. 模型原点重置为**轮胎与地面接触平面几何中心点**；
2. 采用右手笛卡尔坐标系，车头强制朝向 **X轴正方向**，垂直于车的底盘的方向，且竖直朝上的方向为**Z轴正方向**；
3. 对需要执行对抗纹理扰动、遮挡伪装的面片拆分并重命名，便于Python脚本批量筛选、掩膜提取、网格后处理。

## 一、基础统一约定
### 1.1 坐标系强制规则
- 坐标系类型：**右手坐标系**（Blender软件默认为右手系，无需额外配置）
- 轴向定义：
  - +X：车辆车头正前方
  - +Z：竖直向上（垂直地面）
  - +Y：车辆侧面
### 1.2 软件版本兼容
推荐：Blender 5.0 
### 1.3 导入支持模型格式
FBX、OBJ、GLB/GLTF、STL，优先使用FBX/GLB保留层级与UV信息

---

## 二、步骤1：外部车辆模型导入Blender
1. 顶部菜单栏：`文件 -> 导入`，选择对应模型后缀格式；
2. 导入参数关键配置：
   - 向前轴(Forward)：`X`
   - 向上轴(Up)：`Z`
   - 勾选：应用缩放、应用旋转、自动平滑法线；
3. 导入后按需处理：可整体合并网格（`Ctrl+J`），或保留车身、车轮、玻璃等独立物体（推荐拆分，方便后续选面操作）。

---
## 三、步骤2：模型处理
1. **模型原点重置**：将车辆的车轮与地面接触平面几何中心点设置为模型原点，确保模型在Blender中处于正确位置。
2. **模型坐标系转换**：车辆的坐标系参考上面，需跳转。
3. **模型拆分**：将需要执行对抗纹理扰动、遮挡伪装的面片拆分并重命名，便于Python脚本批量筛选、掩膜提取、网格后处理。
4. 注意事项，此过程都是基于blender软件上处理。具体的blender软件的操作步骤，可以参考blender软件的官方文档或视频教程。或者拷打AI。

## 四、步骤3：模型导出
1. **导出格式**：导出为FBX格式，保留层级与UV信息，便于后续处理。
2. **导出参数关键配置**：
  - 向前轴(Forward)：`X`
  - 向上轴(Up)：`Z`
    应该是默认参数，不用修改。
## 五、mtl文件后处理
 模型导出后，mtl文件中材质参数需要修改，主要是导出后可能存在一些路径，此路径需要修改为相对路径，同时mtl材质对应的一些纹理贴图也需要放在同一个文件夹中，其中贴图的路径需要修改为相对路径（即mtl文件中材质的路径）。
